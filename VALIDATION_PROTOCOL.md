# VALIDATION_PROTOCOL

- Gate 1: within-subject ICC on synthetic repeated sessions; report point estimate, bootstrap CI, and failed seeds.
- Gate 2: real non-meditator controls versus meditator baseline stays partial until labeled cessation data exists.
- Gate 3: surrogate EEG must increase distance relative to real collapse epochs.
- Gate 4: conformal coverage target is 0.9, acceptable range is target ± 0.05, and unstable seed sweeps are flagged for review.
- Validation sweeps should use at least 20 seeds when feasible and report bootstrap 95% confidence intervals.
- Recommended ablations: reduced subject/channel support, shorter epochs, and reduced preprocessing/feature families.
